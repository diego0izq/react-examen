# Sistema Web con React - Gestor de Tareas
## Descripción
Aplicación web desarrollada con React que permite gestionar tareas (crear, visualizar y eliminar tareas).  
El sistema utiliza una API simulada con JSON Server para almacenar los datos.

## Tecnologías Utilizadas
- React
- Vite
- Axios
- JSON Server
- JavaScript
